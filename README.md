## Tech Stack

- **HTML5** — Semantic markup
- **Vanilla CSS** — Custom design system with CSS variables (`css/style.css`)
- **Vanilla JS** — Web Components for shared header/footer (`js/header.js`, `js/footer.js`)
- **three.js** (CDN) — 3D scenes ported from solacecarerx.com: the scroll-driven home page film (`js/cinema.js`, `js/cinema3d.js`, `css/cinema.css`) and the vaccine page header scene (`js/page3d.js`), sharing `js/sol3d.js`
- **FormSubmit** — Contact, refill, and vaccine booking forms deliver straight to info@stocktonpharmacy.com (no account required); if the service is unreachable, the form falls back to opening the visitor's email app (mailto)
